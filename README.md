# 子智能体模型选择策略 · Subagent Model Policy

作者：lez · 版本 `0.3.0-rc.1`（预发布）· 目标宿主 DeepSeek Harness `0.2.2-rc.1`。

> 这是预发布版本。核心链路、三页面板与合成回归已通过，但 AC-12 的 GUI 全项验收仍未完成，深度/存活超限等真实场景仍暂缓；不要把本版本表述为稳定版或全项验收版。

在当前会话中管理子智能体的模型选择策略、候选模型池、会话级并发/递归限制，并记录创建时的策略与实际响应证据。默认关闭；安装不会改变主模型、其他会话的模型选择或宿主授权。

## 安装

在 DeepSeek Harness 的插件管理器中安装：

```text
@lienze/dsh-subagent-model-policy@0.3.0-rc.1
```

预发布版本请显式指定版本，不要依赖 `latest`。安装或更新后按当前 Harness 的方式重载插件与页面；源码修改不等于运行实例已更新。若当前 Harness 使用 CLI 管理 profile，按该版本文档把同一包说明符加入对应 profile。

包名中的 `@lienze` 是发布账号的 scope；插件内部的存储域、命令与工具名沿用历史前缀 `lez-`，不影响安装、升级或已保存数据。

## 入口

会话标题栏的「子智能体模型选择策略」按钮，或右侧栏页签中的同名入口。面板包含三个页面：

- **选择策略**：策略开关、新会话默认开关、策略池与页内编辑。
- **模型池**：候选勾选、刷新候选、能力卡、会话并发/递归限制。
- **执行洞察**：本插件记录的真实创建与响应证据。

## 策略语义

- **固定模型**：委派只使用选中的模型；不匹配时报错，不静默替换。
- **Agent 自选**：从会话池候选子集中选择，并在委派时显式填写精确 provider/model。
- 旧版「跟随父模型」策略只读保留；保存为固定或 Agent 自选时显式转换。
- 保存启用中的策略后，新内容在下一次主 Agent 发起模型调用时生效；保存非启用策略只更新策略库，启用后才生效。
- 无改动重复保存不制造新版本；界面不显示内部版本号。
- 当前启用策略和新会话默认的来源策略不可删除；需先关闭策略或更改/清除默认。
- 设置为新会话默认后不弹顶部提示，只更新「新会话默认」开关摘要。
- 关闭策略不会删除策略、不改主模型，也不追溯终止已创建的子智能体。

## 模型池与限制

- 模型池只列出当前宿主允许的候选；勾选不会扩大宿主授权，也不管理 API Key、连接或官方授权。
- 当前启用策略引用的候选受保护，移除会被拒绝并提示先调整或关闭。
- 「刷新候选」按发起瞬间的宿主授权与可用性移除失效候选，并同步清理策略中的失效引用；当前启用内容受保护。
- 模型行显示宿主提供的思考等级与能力卡；未提供时不猜测等级名。
- 并发子智能体数量与最大递归深度为会话公共配置，切换策略不改变；实际委派同时受宿主上限和本会话限制约束。
- 保存启用中策略、启用策略和保存限制共用宿主容量门禁；无法读取宿主容量时拒绝写入并说明原因，保留已启用内容。

## Agent 工具

- `subagent_policy`：读取策略、模型说明、注入预览与运行回读。
- `delegate_with_policy`：创建本地 fresh/fork 子智能体，返回子会话 id；自选模式必须显式提供精确 provider/model 和一句选择依据。完成后由原生 subagent 运行时投递结果。

策略保存不自动创建子任务；是否委派仍由用户任务与 Agent 决定。

## 原生入口边界

原生 `subagent`、`subagent_fork`、`workflow`、`spawn_teammate` 的本地创建只做准入校验，不代填或改写模型参数。固定/自选模式下，原生入口不能指定目标模型时可能被拒绝，此时应改用 `delegate_with_policy`。插件不 monkey-patch、不替换官方工具，也不保证外部后端或非本地创建。

## 证据语义

- `assistant/message`：从子会话自身后缀的模型消息读取实际响应路由。
- `request/header`：只说明拟请求路由，不显示为实际响应。
- `pending`：尚无证据。
- 子 Agent 自述、模型说明和请求配置不能替代实际响应证据。执行洞察保留创建时的策略名，不随之后重命名或删除改写。

## 范围与暂缓

- 覆盖当前会话内的策略库、模型池、默认内容与会话限制；不做跨会话共享策略库或项目级默认。
- 不修改宿主授权、主模型、官方 profile 配置或原生工具参数。
- 宿主撤销授权后，已绑定子 Agent 的后续请求由宿主拒绝，插件不静默回退。
- 预发布阶段未完成 AC-12 全项 GUI 验收；深度/存活真实超限、完整旧数据迁移与策略版本切换等场景仍暂缓。合成测试通过不等于这些场景已实测。

## 卸载

通过 Harness 插件管理器禁用或移除 bundle。插件保存的会话策略与执行记录保留在宿主 storageDomain；重新启用后仍可读取。不要手动编辑 profile 生成的 `package.json`、`cordis.patch.yml` 或 `cordis.yml`。
